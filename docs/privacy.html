プライバシーポリシー

制定日: 2026年8月1日

stotic-dev（以下「運営者」といいます）は、iOSアプリケーション「homete」（以下「本サービス」といいます）における、ユーザーの個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

第1条（取得する情報）

運営者は、本サービスの提供にあたり、以下の情報を取得します。

情報の種類内容
認証情報 Sign in with Apple による認証で発行されるユーザー識別子。氏名・メールアドレスは、Apple側の設定によりユーザーが提供を選択した場合のみ取得されることがあります（メールを非公開にした場合はAppleが発行する匿名メールアドレスとなります）。
プロフィール情報 ユーザーが本サービス上で設定するニックネーム（表示名）。
同居グループ情報 同居グループのメンバー構成、グループへの参加・離脱に関する情報。
家事タスク情報 ユーザーおよび同居グループのメンバーが登録した家事タスクの内容、担当者、完了状況、日時等のコンテンツ。
プッシュ通知用トークン Firebase Cloud Messaging によるプッシュ通知配信のためのデバイストークン（FCMトークン）。
利用状況ログ Firebase Analytics を通じて取得する、ログイン・ログアウト・アカウント削除等の操作イベントログ。
課金・購読情報 アプリ内課金（サブスクリプション等）の購読状況。決済処理自体はAppleのApp Storeが行い、運営者はカード情報等の決済情報を取得しません。
広告関連情報 Google AdMob SDK によるバナー広告の表示・配信に伴い、広告識別子等の情報が取得される場合があります。
端末情報 OSバージョン、アプリバージョン等、不具合解析や品質改善のために必要な技術情報。

第2条（利用目的）

運営者は、取得した情報を以下の目的で利用します。

  • 本サービスの提供・運営・維持のため
  • ユーザー認証およびアカウント管理のため
  • 同居グループ内での家事タスクの共有・管理機能を提供するため
  • 他の同居グループメンバーがタスクを完了した際等のプッシュ通知を配信するため
  • 本サービスの利用状況を分析し、機能改善・品質向上を図るため
  • 広告を配信するため
  • 有料プラン（サブスクリプション）の提供・管理のため
  • 不正利用の防止、利用規約違反への対応のため
  • お問い合わせへの対応のため
  • 本ポリシーまたは利用規約の変更等を通知するため

第3条（第三者提供・外部サービスの利用）

運営者は、法令に基づく場合を除き、あらかじめユーザーの同意を得ることなく、第三者に個人情報を提供することはありません。 ただし、本サービスは以下の外部サービスを利用しており、これらの提供事業者に対して、各サービスの機能提供に必要な範囲で情報を送信します。各社のプライバシーポリシーについても併せてご確認ください。

提供事業者サービス用途
Google LLC（Firebase） Authentication / Firestore / Cloud Messaging / Cloud Functions / Analytics 認証、データ保存、プッシュ通知配信、サーバーサイド処理、利用状況分析
Google LLC（AdMob） Google AdMob アプリ内広告の配信
Apple Inc. Sign in with Apple / App Store ユーザー認証、アプリ内課金の決済処理
RevenueCat, Inc. RevenueCat サブスクリプション（購読状況）の管理

第4条（同居グループ内での情報共有について）

ユーザーが同居グループに登録した家事タスク等のコンテンツ、および表示名は、同じ同居グループに属する他のメンバーに共有されます。 ユーザーは、これらの情報が同居グループ内の他のメンバーに開示されることをあらかじめ承諾のうえ本サービスをご利用ください。

第5条（アカウント削除・情報の取扱い）

  1. ユーザーは、本サービス内の機能によりいつでもアカウントを削除できます。
  2. アカウント削除時、運営者はユーザーのアカウント情報を削除します。
  3. 削除時点で同居グループの残存メンバーが2名以下の場合、当該同居グループおよびそこに紐づく家事タスク・履歴等のデータもあわせて削除されます。
  4. 削除時点で同居グループの残存メンバーが3名以上の場合、退会したユーザーはグループのメンバー一覧から除外されますが、グループ自体および他のメンバーが登録したデータは存続します。
  5. 広告配信事業者・分析事業者等、外部サービス側に送信済みの情報については、各社のプライバシーポリシーおよびデータ保持方針に従います。

第6条（プライバシー・トラッキングについて）

本サービスは、Appleのプライバシー基準に基づき、ユーザーを第三者サービス横断でトラッキングする機能を実装していません。 App Store上のプライバシー情報（プライバシー"栄養"ラベル）もあわせてご確認ください。

第7条（安全管理措置）

運営者は、取得した情報の漏えい、滅失またはき損の防止その他の安全管理のため、Firebaseのセキュリティルールおよびアクセス制御など、必要かつ適切な措置を講じます。

第8条（未成年者の利用について）

未成年のユーザーが本サービスを利用する場合は、保護者等の同意を得たうえでご利用ください。

第9条（プライバシーポリシーの変更）

運営者は、必要と判断した場合には、ユーザーに通知することなくいつでも本ポリシーを変更できるものとします。変更後のプライバシーポリシーは、本ページに掲載した時点より効力を生じるものとします。
