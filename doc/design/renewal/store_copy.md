## description.txt（プレミアムプランの節より上を差し替え）

```
毎日の家事に、ちいさなごほうびを。

homeauは、いっしょに暮らす人と家事を分け合い、おたがいのがんばりに気づけるアプリです。
家事を終えるたびに、イメージキャラクターの「ほめっと」がねぎらってくれます。

できること

・今日やる家事を登録して、ふたりの進み具合をひと目で確かめられます
・家事を終えると、いっしょに暮らす人にお知らせが届きます
・届いたお知らせから、「ありがとう」をひとことで返せます
・誰がどれくらい家事をしたか、グラフでふり返れます
・よくやる家事を「いつもの家事」に登録しておくと、タップするだけで追加できます

こんな方に

・家事の分担が、なんとなく偏っている気がする
・パートナーのがんばりに、もっと気づいてあげたい
・家事をしても、誰にも気づかれないのがさみしい

がんばった家事が、ちゃんと伝わる毎日を。
```
